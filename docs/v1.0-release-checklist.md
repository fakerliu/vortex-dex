## 一、V1.0 功能全景（已全部实现）

### 用户前端（apps/web，11 页）

| 页面 | 模块 | 状态 |
|---|---|---|
| `/swap` | Swap 交易（真实报价 + 路由 + 交易） | ✅ |
| `/explore` | Explore 市场发现榜单（价格 + 24h 成交量） | ✅ |
| `/token/[address]` | Token Detail（元数据 + 价格 + Security 区块） | ✅ |
| `/portfolio` | Portfolio 资产中心（多 token 余额 + USD 估值） | ✅ |
| `/transactions` | 交易历史列表 | ✅ |

| `/analytics` | 用户侧分析 | ✅ |
| `/` | 首页（重定向 /swap） | ✅ |

### 后端（apps/api，12 模块 / 19 路由组）

Token / Quote / Route / Swap / User / Pool / Protocol / Market / Approval / Security / Analytics（含 dex/monitor/anomaly/diagnosis/ai）/ Health。

### Admin 后台（apps/admin，7 页）

登录 / dashboard / dex / monitor / anomaly / diagnosis / ai。

### 核心能力闭环

- **真实报价引擎**：单跳 + 多跳（WETH/USDC hub）路由，Gas 折算净输出排序
- **真实链上执行**：调用官方 Aerodrome/Uniswap Router（非托管，无自有合约）
- **数据真实度标记**：`REAL_ONCHAIN / INTERNAL_CALCULATED / UNAVAILABLE` 全链路落地
- **intent_id 全链路追踪**：前端行为 → 报价 → 路由 → 交易 → 链上确认
- **Indexer**：链上事件幂等写入 + reorg 检测 + 断点续传
- **Analytics 十步**：仪表盘 / DEX 分析 / 监控 / 异常 / 诊断 / AI 摘要

### 3.2 数据真实性

### 3.3 资金安全

- [x] 金额全 BigInt 定点 / Decimal(78,x)，禁 Float

- [x] 后端非托管，不持有用户私钥，签名在客户端
- [x] Approval 授权额度查询（hasAllowance 高亮警告）
